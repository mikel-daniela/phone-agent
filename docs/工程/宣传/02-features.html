人格不在提示词里，在能算的代码里 每一件都会真的影响她下一句怎么回 —— 不是文案，是状态。

01

她会累，也会烦

多巴胺、血清素、催产素、皮质醇四条曲线按小时回落。被夸、被冷落、隔很久才见面，走的是不同的路。

02

作息是她的，不是设定的

夜里聊天会攒睡眠债，第二天精力真会低。久坐、生理期、体检里的异常项，都会改她当下的状态。

03

记忆会淡，不会消失

按情绪强度衰减：吵架那句记得久，随口一句天气很快模糊。模糊时她说"好像提过"，不会假装没听见。

04

世界书靠类型防崩

设定只能你写（SETTING），她只能提事实（FACT）且要你点头。她提的事永远盖不掉你写的设定。

05

三种模式，一份人格

角色扮演 / 工作台 / 在场，只切允许她做什么，不换人。工作模式压掉客服腔，也能边干边聊。

06

工具日志看得懂

调工具时一行一行滚：工具名、参数、成功 / 失败 / 被拦颜色不同。失败那一步是能看见的，不用猜。
