# 宣传配图（0.1.0-m2）

三张图，都给公众号 / README / 社交预览用。色板取自 app 自己的设计令牌
（纸色 `#F7F3EA`、墨色 `#1F1B18`、强调色 `#C96442`），所以图和产品是一套皮。

| 文件 | 尺寸 | 用在哪 |
|---|---|---|
| `01-cover.png` | 1080×460（≈2.35:1） | 公众号首图 / 文章头图 |
| `02-features.png` | 1080×1200（9:10） | 正文第一屏，六条特性 |
| `03-modes.png` | 1080×760 | 讲「三种模式不是三套人格」 |

## 怎么重新生成

三份 `.html` 就是源文件，改字改色都改它们：

```bash
# 1) 用浏览器打开（Chrome / Edge 都行）
start docs\工程\宣传\01-cover.html

# 2) 截图后按上表尺寸裁掉右边与下边的空白
#    01 裁 (0,0,1080,460)；03 裁 (0,0,1080,760)
#    02 高 1200 > 一屏，分两次截（滚动 0 与滚动 400）再拼：
#    先截 0..400 贴顶部，再截 400..1200 贴下面
```

字体：`Microsoft YaHei` / `PingFang SC`，数字用 `Georgia` 与 `tabular-nums`。
没有引入任何外链字体与图片 —— 离线也能重出，不会因为 CDN 挂了变成方块。

## 说明

- 图里出现的数字（12 条技能、0.1.0-m2）都是从代码与 `android/app/build.gradle.kts`
  里抄的，改版本时记得同步。
- 曲线不是装饰：`01-cover.png` 那条是 `PhysiologyEngine` 的警觉度锚点
  （04:00 低 → 10:00 高 → 23:00 低）大致形状。
