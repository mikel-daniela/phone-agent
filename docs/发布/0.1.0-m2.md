# PocketAgent 0.1.0-m2

第二里程碑。仍然不是"能用的助理"，而是**先把人格这条腿站稳**：她的状态会变，
记忆会淡，说话不该像客服。安装包见本页底部 Assets。

> ⚠️ 这个包没有内置任何 API Key。第一次打开要去「设置 → 模型 / API Key」填自己的，
> 支持 OpenAI 兼容、Anthropic、以及国内几家的兼容端点。不填就只会回一句"还没配模型"。

## 这一版新东西

### 她会变

- **激素**：多巴胺 / 血清素 / 催产素 / 皮质醇，四条曲线按时间回落到基线。
  被夸、被冷落、被凶、隔了很久又见面，各自走不同的路；皮质醇高的时候催产素压不上去。
- **生理**：作息在场（几点、清醒度）、睡眠债、久坐。夜里聊太久，第二天她会累。
- **生理期**：按体检报告里的周期推算，经期头两天精力更低；**刻意没有**去动血清素
  ——"来例假=情绪差"这种写法不是人格，是刻板印象。
- **体检报告**：按现代体检的结构填（血压、血常规、生化、甲功、心电、影像、营养），
  外加报告写不下的部分（怕疼、怕针、体味、旧伤、过敏、说话习惯）。贫血、甲减这些
  异常项会真的影响她的精力，不只是文案。
- **意愿**：聊得太久、或在气头上，她可能说"今天不太想聊"。默认阈值很低，
  开关在设置里，关掉就是永远有求必应（意愿仍影响语气，但不会拒绝）。

### 她会记得，也会忘

- 记忆按**情绪强度**衰减：吵架那句记得久，随口一句天气很快模糊。
  模糊不是删除——她会说"好像提过"，而不是假装没听过。
- 三个场景（聊天 / 工作台 / 在场）的**关键记忆互通**：在哪说的不丢，但都读得到。
- **世界书**：设定由你定（`SETTING`），她只能提事实（`FACT`）且必须你点头才入库；
  她提议的事实**永远盖不掉**你写的设定。这是防止长对话把设定聊崩的机制，
  靠类型分开，不靠提示词里写"请不要改设定"。
- **场记**：每几轮在后台判断这一轮有没有值得记的事，输出的是**事件**，不是数值。

### 三个模式不是三套人格

- 角色扮演 / 工作 / 在场，共用一份人格，只切换**允许做什么**。
- 工作模式不再端着：压掉客服腔，允许她露出一点自己的态度；
  设置里还有「边干边聊」——干活时能顺口带两句生活里的话。
- 工作台是独立页面，标题是「（昵称）的工作台」，开场白按时段和近况随机。

### 干活

- **工作技能**：内置 12 条（八条做法 + 四张速查），每条都标了出处，不是凭空编的
  ——金字塔原理与 SCQA、Diátaxis、Google 技术写作、ICAEW 电子表格二十条、
  MECE、Amazon 六页备忘录、OKR、pre-mortem、Tufte 与 Knaflic 的图表原则。
  工作台里打 `/` 直接挑，也能导入自己的 `.md`；不打 `/` 说一句话也能触发。
- **工具日志**：调用工具时按 Claude Code 那种单行日志滚动（工具名 + 参数 + 状态），
  失败和被拦颜色不同——原来一律是一行灰字，看不出哪步出事。
- **演示文稿**：生成的 PPT 有封面、章节页、页码和配色，不再是一页一页的白底黑字。
- 生成的文件卡片**不再压住回复正文**（`AnimatedVisibility` 的叠放语义踩的坑）。

### 说话

- 语音：三段开关（文字 / 都有 / 语音）+ 顶部小喇叭，不用再进设置。
  音色可从厂商音色库挑，支持自定义标签（`[轻笑]` 这类只发给语音模型，不上屏）。
- 去 AI 味：禁令配替代动作、输出清洗、提示词卫生。第三声"白送"也算 AI 味，
  所以示例刻意写得不齐整。

## 已知问题

- 后台的「场记」有时几轮都不产出小事（返回空 JSON），不影响主对话。
- 语音条的真实时长偶有偏差。
- 通话闭环（录音 → 转写 → 模型 → 播报）只在真机跑过单轮，长对话未压测。
- 屏幕共享需要手动开无障碍服务。

## 装

1. 下载下方 APK。
2. 允许"安装未知来源"。
3. 首次进入填 API Key。
4. 需要无障碍 / 通知 / 麦克风的能力，用到时再授权。

签名指纹见 `apk/SHA256SUMS.txt`；换个签名装的包装不上去，会提示"应用未安装"。
